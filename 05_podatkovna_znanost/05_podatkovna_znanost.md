# Uvod u podatkovnu znanost

Podatkovna znanost je interdisciplinarno područje koje se bavi prikupljanjem, analizom i interpretacijom velikih količina podataka kako bi se izvukle korisne informacije i donijele informirane odluke.

## Dodatni materijali

- [Kaggle Pandas](https://www.kaggle.com/learn/pandas) - besplatni tečaj koji pokriva osnove rada s Pandas bibliotekom, koja je ključni alat za manipulaciju i analizu podataka u Pythonu.
- [Kaggle Data Visualization](https://www.kaggle.com/learn/data-visualization) - tečaj koji se fokusira na vizualizaciju podataka koristeći popularne biblioteke poput Matplotlib i Seaborn.
- [Data Science Handbook](https://jakevdp.github.io/PythonDataScienceHandbook/) - besplatna knjiga koja pokriva osnove podatkovne znanosti koristeći Python i popularne biblioteke poput NumPy, Pandas, Matplotlib i Scikit-learn.
- [Introduction to Modern Statistics](https://openintrostat.github.io/ims/) - besplatna knjiga koja pokriva osnove statistike, što je ključni dio podatkovne znanosti.
